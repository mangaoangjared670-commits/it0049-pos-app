# IT0049 - Technical Formative Assessment 1
## Point-of-Sale (POS) System

A 4-page CodeIgniter 4 application using MVC architecture and static PHP arrays.

### Requirements & Setup
1. XAMPP (PHP 8.1+ with `intl` extension enabled)
2. Apache Web Server

### How to Run Locally
1. Clone or download this repository into your `htdocs` folder:
   `C:\xampp\htdocs\my-ci4-app`
2. Start Apache via the XAMPP Control Panel.
3. Open your browser and navigate to:
   `http://localhost/my-ci4-app/public/`

### Application Pages / Routes
- `/` - Home Page
- `/about` - About POS System
- `/customers` - Customer Accounts List
- `/users` - User Accounts List
